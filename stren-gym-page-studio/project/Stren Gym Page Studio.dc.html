Gym Page Studio

Replace the single long form in app/admin/gym-profile/page.tsx with a guided, preview-first studio. The public layout stays predefined — owners make guided choices only (photos, logo, colors, copy, section visibility, publish). Keep every upload / compress / hash / storage / save path exactly as it is; this is a UI change around that logic.

├─ GettingStartedBanner  // dismissible checklist
├─ StudioHeader          // status · save · publish
├─ ControlRail           // desktop left / mobile stack

The one refactor that unlocks it

Extract the presentational body of GymLandingPage (currently defined inside app/gym/[code]/page.tsx) into a prop-driven component:

components/gym/GymLandingPreview.tsx props: { gym, view, device, focal, safeArea?, interactive? } view: 'home'|'join'|'contact' |'pricing'|'locate'
  • The public page renders it at device from viewport, interactive=false.
  • The studio preview renders the same component per tab, driven by unsaved state — so what owners see is genuinely the public output, not a mock.
  • Reuse the same pattern for the Contact / Pricing / Locate bodies (one component keyed by view, or three thin siblings).

UI states to handle
  • Empty — no cover / logo / tagline → dashed add-affordance + checklist nudge
  • Uploading — spinner on the field, Save disabled (existing flag)
  • Dirty → Saving → Saved — header reflects each; autosave optional
  • Published vs Hidden — publish gated on tagline (existing rule)
  • Low contrast — warn + suggest a deeper shade
  • Section hidden — toggle removes it from the live preview
  • Focal editing — drag dot; arrow keys nudge 1%
  • Drawer open/closed (mobile)
Responsive & accessibility
  • ≥1024px — two-pane (rail + sticky preview), layout 1a
  • <1024px — stacked controls + sticky Preview drawer, layout 1b
  • All toggles are real role="switch" buttons with labels
  • Focal point keyboard-operable; announces X/Y %
  • Safe-area guide guarantees hero text never overlaps busy photo regions
  • Colors ship only when contrast passes; alt text from gym name
Guardrails — do NOT add

No freeform canvas, drag-to-reorder, font/spacing controls, arbitrary section ordering, or nav/checkout editing. Owners can't break the layout — that's the point. This is Notion / Wix-ADI confidence, not a website builder. Preserve the Supabase media-path flow (hashed filenames, versioned cleanup) verbatim.

Tests
  • Extend tests/e2e/admin-gym-preview.spec.ts: studio loads, tabs switch, publish gated on tagline
  • Unit: contrastRatio, focal clamp/normalize, generatePalette

Prototype note: cover photos here are generated placeholders so focal-point cropping is visible offline; in production the owner's uploaded image flows through the existing compress/hash pipeline unchanged.
